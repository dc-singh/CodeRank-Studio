# CodeRank Studio Portfolio

A modern landing page for CodeRank Studio, a digital growth agency focused on high-performance backend systems and technical SEO that drive measurable business growth.

## Description

This project showcases CodeRank Studio’s services, portfolio case studies, and client trust signals in a polished one-page experience. It is designed to present the agency as a specialist partner for backend engineering, search growth, and technical optimization.

The website highlights projects involving FastAPI, Python, SQLAlchemy, Redis, and technical SEO strategies that increase revenue, traffic, and infrastructure efficiency.

## Features

- Smooth scrolling single-page layout
- Responsive landing page design for desktop and mobile
- Hero section with clear agency positioning
- Service cards for backend development and SEO growth
- Portfolio/case study highlights with performance metrics
- Client testimonials and trust-building content
- Consultation CTA and modal-based lead capture
- Modern visual design using React and Tailwind CSS

## Tech Stack

- Frontend: React, TypeScript, Vite
- Styling: Tailwind CSS
- Build Tool: Vite
- Additional Libraries: clsx, tailwind-merge

## Installation / Setup

Follow the steps below to run the project locally:

```bash
git clone <repo-url>
cd coderank-studio-landing-page
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal, usually:

```bash
http://localhost:5173
```

## Usage

- Navigate through the page sections to explore services, case studies, testimonials, and CTA areas.
- Use the consultation button to open the lead capture modal.
- Review the agency positioning and growth-focused messaging designed for client acquisition.
- Use the page as a portfolio/marketing landing page for a backend + SEO brand.
